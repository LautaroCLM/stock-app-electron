📌 PROYECTO: Inventario StockApp / Inventario Baupi
Documento de evolución, progreso y próximos pasos
1. Inicio del proyecto

El objetivo inicial fue crear una aplicación profesional de gestión de inventario para un negocio, buscando reemplazar procesos manuales y tener un sistema propio.

La idea principal era desarrollar una aplicación de escritorio capaz de:

Controlar stock en tiempo real.
Registrar ventas.
Gestionar productos.
Tener historial de movimientos.
Manejar clientes y proveedores.
Generar tickets.
Exportar información.
Trabajar sin depender completamente de internet.
Tener sincronización online para respaldo.

La aplicación fue desarrollada utilizando:

Electron como framework de escritorio.
JavaScript como lenguaje principal.
SQLite como base de datos local.
Supabase como backend online.
better-sqlite3 para manejo rápido de base local.
electron-builder para generar instaladores.
2. Arquitectura inicial

Se decidió trabajar con una arquitectura híbrida:

Base local (SQLite)

La aplicación tiene una base local para:

Velocidad.
Uso offline.
Evitar depender de internet.
Respuesta inmediata en ventas.

Ejemplo:

Cuando se realiza una venta:

El usuario cobra.
Se descuenta stock localmente.
Se genera el ticket.
Se guarda la operación en SQLite.
Base online (Supabase)

Supabase se utiliza como respaldo y sincronización.

La idea fue implementar:

Dual Write

Cada operación importante se escribe en:

SQLite local.
Supabase online.

Ejemplo:

Venta realizada:

Venta confirmada
        ↓
Guardar en SQLite
        ↓
Enviar copia a Supabase

Esto permite:

Tener datos seguros.
Recuperar información.
Poder agregar futuras funciones online.
